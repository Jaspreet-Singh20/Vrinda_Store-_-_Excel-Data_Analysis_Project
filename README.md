# Vrinda_Store-_-_Excel-Data_Analysis_Project
The Vrinda Store Excel Project is a data analysis project focused on understanding sales performance, customer behavior, and business trends using Microsoft Excel. The project involves cleaning and organizing sales data, performing calculations, creating pivot tables, and developing interactive charts and dashboards.

## Project Overview  📊

The **Vrinda Store Excel Project** is a data analysis and visualization project created using **Microsoft Excel**. The project focuses on analyzing sales data to understand sales performance, customer behavior, product categories, and order trends.

## Objectives

* Analyze sales and order performance
* Identify popular product categories
* Understand customer purchasing patterns
* Analyze sales by gender and age group
* Compare sales across different states
* Identify monthly sales trends
* Create an interactive Excel dashboard
* Generate useful business insights

## Tools & Skills Used

* Microsoft Excel
* Data Cleaning
* Excel Formulas
* PivotTables
* Pivot Charts
* Data Visualization
* Dashboard Creation
* Data Analysis
* Business Insights
* Sorting and Filtering

## Project Workflow

### 1. Data Cleaning

Prepared and organized the raw sales data for analysis.

### 2. Data Analysis

Used Excel formulas and PivotTables to analyze sales, orders, customers, products, and regions.

### 3. Data Visualization

Created charts and graphs to present important trends and patterns.

### 4. Dashboard

Built an Excel dashboard to present key performance indicators and visual insights.
